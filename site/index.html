BEFORE THE FIRST HELLO

有些事，先说清楚。

真的免费吗？

开源程序免费分发。真实聊天使用你自己的 DeepSeek API Key，模型提供方可能按调用计费；服务器、域名或其他外部服务费用自理。这里不代充、不代收模型费用，也不承诺免费额度。

可以用微信吗？

当前产品验证范围是 QQ 文字聊天。微信与其他平台不在本版验收承诺内。

安装好了，是不是就会自动回复所有人？

不会。保存设置、扫码或重启都不应该自动开启回复。你需要选择明确允许的会话，再从单次试运行开始；群聊默认只响应真正 @ 机器人账号的消息。

关掉页面以后还在回复吗？

关闭浏览器不等于停止程序。先在控制台暂停，再停止运行进程。电脑休眠、关机或断网都可能中断服务。

国内网络一定能顺利下载吗？

网页、安装包、Node.js、容器镜像和模型 API 是不同链路。实际可用性要逐项验证；未完成的国内网络检查会保留待验收标识，不把页面能打开当作安装全过程已通过。
